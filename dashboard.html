    ID ชื่อ วงจร IP พิกัด สถานะ รายงานล่าสุด

    ตั้งค่าการเชื่อมต่อ API

    อุปกรณ์ที่เงียบเกินเวลานี้จะถูกนับเป็น UNKNOWN แทน UP/DOWN เพราะไม่รู้สถานะจริงแล้ว (MikroTik ดับ / เน็ตขาด / สคริปต์หาย) — ใช้ได้ต่อเมื่อลงสคริปต์ Scheduler ครบทุกตัวแล้ว ค่าที่เหมาะคือ 3 เท่าของ interval ที่ตั้งไว้ ใส่ 0 เพื่อปิดการตรวจ

    รูปแบบข้อมูลที่รองรับ — API ควรตอบกลับ JSON แบบใดแบบหนึ่งต่อไปนี้:

    1) แบบสรุปยอดแล้ว

    {
  "recorder":    {"up":33,"down":0,"unknown":0},
  "camera":      {"up":707,"down":12,"unknown":0},
  "transmitter": {"up":0,"down":0,"unknown":0},
  "receiver":    {"up":0,"down":0,"unknown":0},
  "router":      {"up":6,"down":0,"unknown":0},
  "accesspoint": {"up":126,"down":1,"unknown":0}
}

    2) แบบรายอุปกรณ์ (ระบบจะนับให้อัตโนมัติ)

    [
  {"category":"camera","status":"up"},
  {"category":"router","status":"down"},
  ...
]
